title: Submit data to NWESDAP
---

The initial version of the NWESDAP dataset is now finalised and no longer open for additional submissions.

We do plan to release updated versions with additional datasets in the future, although the system for this still needs to be set up.  In the meantime, please feel free to get in touch at [info@nwesdap.net](mailto:info@nwesdap.net) if you would like to be kept informed.
